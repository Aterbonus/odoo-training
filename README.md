# Odoo training

Repositorio con lo realizado en el curso [Technical Training - Introduction to Development](https://www.odoo.com/es/slides/technical-training-introduction-to-development-318).

El curso originalmente está hecho en Odoo 17, pero el curso fue realizado
en Odoo 20.

El repositorio cuenta con una pequeña configuración para usar Odoo en
con Docker.
